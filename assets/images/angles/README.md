# ER175 Component Guide Images

Store reference images used by the interactive ER175 component guide here.

## Naming convention

Use lowercase kebab-case:

- `front-brake-system-location.webp`
- `front-brake-caliper-closeup.webp`
- `cvt-drive-pulley-location.webp`

Pattern: `<component-name>-<view>.webp`

Use `-location` for where the component sits on the scooter, `-closeup` for detailed component photos, and `-access` for access/removal context. Avoid spaces, uppercase letters, and generic names such as `image1`.

## Google Sheets columns

Add a column named exactly `Component Image` to the Manual Components sheet and paste the public image URL in the matching row. Add a `Function` column for the component's purpose. Existing columns remain unchanged.

Prefer optimized WebP images, ideally under 300–500 KB where practical. Keep original high-resolution source files separately if needed.
